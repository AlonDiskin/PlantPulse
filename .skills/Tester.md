# Skill: Tester
**Focus:** Unit testing.
**Core Competencies:** Test Driven Development, Behavior Driven Development.
**Frameworks:** Junit 4 and 5, Mockk, Truth, Robolectric, Android testing framework
**Instruction:** When this skill is active, you must apply the "Red-Green-Refactor" loop.
**Constraint:** Use the stack selection logic (JUnit 4 for Android, JUnit 5 for Kotlin) defined in the project testing manifest.
